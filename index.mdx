Synapse Protocol is a cross-chain interoperability platform that lets you bridge tokens, send messages, and build multi-chain applications across 19+ EVM-compatible networks. The monorepo contains everything from Solidity contracts and off-chain agents to a TypeScript SDK, embeddable React widget, and a production REST API.

## Key integration steps

<Steps>
  <Step title="Choose your integration path">
    Use the **TypeScript SDK** for full programmatic control, the **REST API** for simple HTTP calls, or the **React widget** for a zero-config UI.
  </Step>
  <Step title="Get bridge quotes">
    Call `allBridgeQuotes()` (SDK) or `GET /bridge` (REST API) to compare routes across SynapseBridge, SynapseCCTP, and SynapseRFQ modules.
  </Step>
  <Step title="Execute bridge transactions">
    Use the returned quote to populate and submit a transaction on the origin chain. The protocol handles routing and settlement on the destination.
  </Step>
  <Step title="Track transaction status">
    Poll `getBridgeTxStatus()` or `GET /bridgeTxStatus` to confirm when funds arrive on the destination chain.
  </Step>
</Steps>
