---
title: "RFQ quotes: GET /quotes, PUT /quotes, and PUT /bulk_quotes"
description: "Query active relayer quotes, submit or update a single quote, or upsert many quotes in one request using the Synapse RFQ API quote endpoints."
---

The Synapse RFQ (Request-For-Quote) system connects users who want to bridge with a network of off-chain relayers who compete to provide the best rates. Relayers publish their willingness to relay specific token pairs at specific prices by upserting quote records. Users and aggregators query those quotes to find the best available rate before initiating an RFQ.

There are three quote-management endpoints:

- **`GET /quotes`** — Read currently active quotes filtered by token pair and relayer.
- **`PUT /quotes`** — Submit or update a single quote from a relayer.
- **`PUT /bulk_quotes`** — Upsert multiple quotes from a relayer in one request.

---

## GET /quotes

```
GET https://api.synapseprotocol.com/quotes
```

Returns all active quotes matching the specified origin chain, destination chain, token addresses, and relayer address. The response is an array of quote objects — one per relayer/route combination.

### Query parameters

<ParamField query="originChainID" type="integer" required>
  Chain ID of the origin chain to filter by.
</ParamField>

<ParamField query="originTokenAddr" type="string" required>
  Contract address of the origin token to filter by.
</ParamField>

<ParamField query="destChainID" type="integer" required>
  Chain ID of the destination chain to filter by.
</ParamField>

<ParamField query="destTokenAddr" type="string" required>
  Contract address of the destination token to filter by.
</ParamField>

<ParamField query="relayerAddr" type="string" required>
  Ethereum address of the relayer to filter by.
</ParamField>

### Response fields

An array of quote objects.

<ResponseField name="origin_chain_id" type="integer">
  Chain ID the relayer will relay from.
</ResponseField>

<ResponseField name="origin_token_addr" type="string">
  Token address on the origin chain the relayer accepts.
</ResponseField>

<ResponseField name="dest_chain_id" type="integer">
  Chain ID the relayer will relay to.
</ResponseField>

<ResponseField name="dest_token_addr" type="string">
  Token address on the destination chain the relayer will deliver.
</ResponseField>

<ResponseField name="dest_amount" type="string">
  Maximum amount of destination token liquidity the relayer can provide, in the destination token's native decimals.
</ResponseField>

<ResponseField name="max_origin_amount" type="string">
  Maximum origin token amount the relayer will accept for this route.
</ResponseField>

<ResponseField name="fixed_fee" type="string">
  Fixed fee charged by the relayer, denominated in the destination token.
</ResponseField>

<ResponseField name="origin_fast_bridge_address" type="string">
  Address of the FastBridge contract on the origin chain.
</ResponseField>

<ResponseField name="dest_fast_bridge_address" type="string">
  Address of the FastBridge contract on the destination chain.
</ResponseField>

<ResponseField name="relayer_addr" type="string">
  Ethereum address of the relayer providing this quote.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last time this quote was upserted.
</ResponseField>

### Example request

```bash
curl "https://api.synapseprotocol.com/quotes\
?originChainID=1\
&originTokenAddr=0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48\
&destChainID=42161\
&destTokenAddr=0xaf88d065e77c8cc2239327c5edb3a432268e5831\
&relayerAddr=0xRelayerAddress"
```

## PUT /quotes

```
PUT https://api.synapseprotocol.com/quotes
```

Submit a new quote or update an existing one. If a quote for the same relayer and token pair already exists, it is replaced. The request body must be a JSON object matching the `PutRelayerQuoteRequest` schema.

### Request body

<ParamField query="origin_chain_id" type="integer" required>
  Chain ID the relayer will relay from.
</ParamField>

<ParamField query="origin_token_addr" type="string" required>
  Token contract address on the origin chain.
</ParamField>

<ParamField query="dest_chain_id" type="integer" required>
  Chain ID the relayer will relay to.
</ParamField>

<ParamField query="dest_token_addr" type="string" required>
  Token contract address on the destination chain.
</ParamField>

<ParamField query="dest_amount" type="string" required>
  Maximum destination token amount the relayer can provide, in native decimals.
</ParamField>

<ParamField query="max_origin_amount" type="string" required>
  Maximum origin token amount the relayer will accept.
</ParamField>

<ParamField query="fixed_fee" type="string" required>
  Fixed fee in destination token terms.
</ParamField>

<ParamField query="origin_fast_bridge_address" type="string" required>
  FastBridge contract address on the origin chain.
</ParamField>

<ParamField query="dest_fast_bridge_address" type="string" required>
  FastBridge contract address on the destination chain.
</ParamField>

### Example request

```bash
curl -X PUT "https://api.synapseprotocol.com/quotes" \
  -H "Content-Type: application/json" \
  -d '{
    "origin_chain_id": 1,
    "origin_token_addr": "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48",
    "dest_chain_id": 42161,
    "dest_token_addr": "0xaf88d065e77c8cc2239327c5edb3a432268e5831",
    "dest_amount": "5000000000",
    "max_origin_amount": "5000000000",
    "fixed_fee": "1000000",
    "origin_fast_bridge_address": "0xOriginFastBridge",
    "dest_fast_bridge_address": "0xDestFastBridge"
  }'
```

### Example response

```json
{}
```

A `200 OK` with an empty body indicates the quote was accepted.

## PUT /bulk_quotes

```
PUT https://api.synapseprotocol.com/bulk_quotes
```

Upsert multiple quotes in a single request. The body is a JSON object with a `quotes` array, where each element is a `PutRelayerQuoteRequest` object (same schema as `PUT /quotes`).

### Example request

```bash
curl -X PUT "https://api.synapseprotocol.com/bulk_quotes" \
  -H "Content-Type: application/json" \
  -d '{
    "quotes": [
      {
        "origin_chain_id": 1,
        "origin_token_addr": "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48",
        "dest_chain_id": 42161,
        "dest_token_addr": "0xaf88d065e77c8cc2239327c5edb3a432268e5831",
        "dest_amount": "5000000000",
        "max_origin_amount": "5000000000",
        "fixed_fee": "1000000",
        "origin_fast_bridge_address": "0xOriginFastBridge",
        "dest_fast_bridge_address": "0xDestFastBridge"
      },
      {
        "origin_chain_id": 10,
        "origin_token_addr": "0x0b2C639c533813f4Aa9D7837CAf62653d097Ff85",
        "dest_chain_id": 8453,
        "dest_token_addr": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
        "dest_amount": "2000000000",
        "max_origin_amount": "2000000000",
        "fixed_fee": "500000",
        "origin_fast_bridge_address": "0xOriginFastBridge2",
        "dest_fast_bridge_address": "0xDestFastBridge2"
      }
    ]
  }'
```

### Example response

```json
{}
```

A `200 OK` with an empty body indicates all quotes were accepted.
